# KH Wake Modeling

Manuscript project targeting **Wind Energy Science** (Copernicus Publications).

## Status

Project initialized. Run `/onboard` in Claude Code to configure project details.

## Structure

- `manuscript/` — Markdown section files (authoritative source of truth)
- `Figures/` — Exported figures
- `scripts/` — Analysis and utility scripts
- `master_supporting_docs/` — Reference papers
- `quality_reports/` — Plans, session logs, data verification
- `explorations/` — Research sandbox

## Workflow

This project uses the [Claude Code Academic Workflow](https://psantanna.com/claude-code-my-workflow/) for AI-assisted manuscript development. Key commands:

| Command | What It Does |
|---------|-------------|
| `/onboard` | First-run project configuration |
| `/review-paper [file]` | Comprehensive manuscript review |
| `/proofread [file]` | Grammar/typo/consistency review |
| `/lit-review [topic]` | Literature search + synthesis |
| `/commit` | Stage, commit, PR, merge |
